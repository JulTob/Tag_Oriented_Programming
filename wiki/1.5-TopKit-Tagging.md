# Tagging: training, admission and the Contract

**Valid source → Gate → Gainings → Imprints → FieldAdding → Posts**

Each missing Tag takes its own turn, Bases first. Existing Posts must hold
before the next Tag's Gate: a Form describes layering, not a promise that a
later Shape will repair a broken Base. All Record spaces are prepared before
any Gain or initializer runs. Preconditions are transient Tagging Services;
they never become Agent names or Contract status.

Gainings become visible top to bottom. Record initializers calculate their
values; Imprints perform training. An ordinary failure in either produces
one named warning and later training continues. The Agent then enters the
Field, and its current Posts judge it. A failed Post leaves a deficient member:
a broken assembled car is still a car. A failed training step with passing
Posts returns a sound Agent with warnings. Optional missing Gains are not
hidden requirements: a Post can require them with `"engine" @ agent`.

The Python blocks below run in order as one program.

## Best-effort training still admits the Agent

```python
import warnings

from TopKit import (Action, Constant, Contract, Imprint, Post, Pre, Public, Record,
                    Report, Rip, Tag, TaggingFailure, TagPostconditionError,
                    TagTargetError, TrainingWarning)


class Host:
    def __init__(agent):
        agent.allowed = True
        agent.training_ready = False
        agent.attempts = []


class Driver(Tag):
    @Pre
    def May_Train(agent):
        return agent.allowed

    @Action
    def Start(agent):
        return agent.engine

    @Record
    def engine(agent):
        return "assembled"

    @Record
    def initial_check(agent):
        return agent.Start()             # earlier Action and Record are visible

    @Public
    @Report
    def badge(tag):
        return "Driver Agency"

    @Imprint
    def Train(agent):
        assert agent not in Driver[:]   # training precedes this Field entry
        agent.attempts.append("training")
        if not agent.training_ready:
            raise RuntimeError("training step failed")

    @Imprint
    def Finish(agent):
        agent.attempts.append("finish")  # still runs after Train fails


driver = Host()
with warnings.catch_warnings(record=True) as training:
    warnings.simplefilter("always", TrainingWarning)
    assert Driver(driver) is driver

assert len(training) == 1
assert isinstance(training[0].message, TrainingWarning.Train)
assert training[0].message.tag_name == "Driver"
assert driver in Driver and driver in Driver[:]
assert isinstance(driver, Driver)
assert "Start" @ driver and "engine" @ driver
assert driver.initial_check == "assembled"
assert driver.Start() == "assembled"
assert driver.attempts == ["training", "finish"]
assert Contract.Status(driver) == {}     # no Posts means no broken promise
assert not ("May_Train" @ driver)        # Pre Services never become Gains
assert driver.badge == "Driver Agency"  # published after FieldAdding
```

Calling an active Tag again is a no-op, including a defective member; it is
not an implicit recovery system. Repair existing Gains first. To start new
training, explicitly Rip and reTag, with the remaining Posts valid:

```python
driver.training_ready = True
Driver(driver)
assert driver.attempts == ["training", "finish"]

del Driver[driver]
Driver(driver)
assert driver in Driver
assert driver.attempts == ["training", "finish", "training", "finish"]
```

A failed Record initializer also warns and continues. Its previous value,
or absence, stays until a later successful write. A Constant Record is not
locked by an initializer that never establishes a value. The warning's
`failure` holds the named TOP diagnostic; copied cause details and source
coordinates describe the original exception without retaining its live
traceback. Warning filters may turn a warning into an exception, but cannot
undo admission.

During training this Tag's published Reports, Operations and bound view are
unavailable through the Agent. Previously admitted Tags keep their own access
rules. Re-entering the same in-progress Tagging is also a no-op.

## A failed Record stays absent; Posts state what is required

Here a failed initializer does not prevent the next Record or Imprint. Two
Posts state the requirements, so the admitted Agent is deficient and one final
error names both broken promises:

```python
class Assembled(Tag):
    @Record
    def engine(agent):
        raise RuntimeError("engine could not be initialized")

    @Record
    def chassis(agent):
        return "assembled"

    @Post
    def Has_Engine(agent):
        return "engine" @ agent

    @Post
    def Brakes_Ready(agent):
        return agent.brakes_ready

    @Imprint
    def Finish(agent):
        agent.attempts.append("finish")


product = Host()
product.brakes_ready = False
with warnings.catch_warnings(record=True) as training:
    warnings.simplefilter("always", TrainingWarning)
    try:
        Assembled(product)
    except TaggingFailure as error:
        assert error.failed_posts == ("Has_Engine", "Brakes_Ready")
    else:
        raise AssertionError("broken required Posts were accepted")

assert len(training) == 1
assert isinstance(training[0].message, TrainingWarning.engine)
assert not ("engine" @ product)
assert product.chassis == "assembled"
assert product.attempts == ["finish"]
assert product in Assembled[:] and product in ~Assembled
```

A failed initializer over an existing binding preserves that binding rather
than erasing it. If the remaining current Posts hold, the same warning would
accompany a normal return instead of a final Post error.

## Structural preparation happens before any Gain

Preparing Record space is separate from calculating its value. A host property
or slot that blocks a Record is a Target Failure, before any initializer or
Action is acquired:

```python
preparation_events = []


class Unsuitable:
    @property
    def engine(agent):
        return "host-owned engine"


class Factory(Tag):
    @Action
    def Start(agent):
        return agent.engine

    @Record
    def engine(agent):
        preparation_events.append("initializer ran")
        return "new engine"


unsuitable = Unsuitable()
try:
    Factory(unsuitable)
except TagTargetError:
    pass
else:
    raise AssertionError("a protected Record space was accepted")

assert type(unsuitable) is Unsuitable
assert preparation_events == []
assert unsuitable not in Factory[:]
```

Failed initial host preparation restores its original representation. Earlier
completed Tags remain. This is not a transaction over mutable Python values
or external effects. A later structural failure that prevents admission can
leave acquired non-Post Gains without this membership, but discards its
provisional Posts, including Constants.

## Guard an Action explicitly

A training failure does not automatically block ordinary Actions. Use an
explicit guard for an effect that requires a particular promise:

```python
class Electric(Tag):
    @Constant
    @Post
    def Insulated(agent):
        return agent.insulated

    @Action
    def Energize(agent):
        if not agent.Insulated:
            raise PermissionError("insulation is required")
        agent.high_voltage = True       # effect only after the explicit guard
        return "energized"

    @Imprint
    def Assemble(agent):
        if not agent.training_ready:
            raise RuntimeError("assembly step failed")


electric = Host()
electric.insulated = False
electric.high_voltage = False
with warnings.catch_warnings(record=True) as training:
    warnings.simplefilter("always", TrainingWarning)
    try:
        Electric(electric)
    except TagPostconditionError.Insulated:
        pass
    else:
        raise AssertionError("a broken Post was accepted")

assert len(training) == 1
assert isinstance(training[0].message, TrainingWarning.Assemble)
assert electric in Electric[:] and electric in ~Electric
assert electric not in Electric
assert Contract.Status(electric) == {"Insulated": False}
assert not electric
try:
    electric.Energize()
except PermissionError:
    pass
else:
    raise AssertionError("an unsafe Agent was energized")
assert not electric.high_voltage

electric.insulated = True               # repair an existing Gain
assert electric in Electric
assert electric.Energize() == "energized"
assert electric.high_voltage
```

Every current visible Post is checked after admission. One failed Post raises
its named error; several produce one `TaggingFailure`, whose `failed_posts`
names them in evaluation order. Training still gives one warning per failed
step. Current Posts define requirements; use `@Constant` when a promise must
remain protected.

`assert agent.Insulated` is compact, but Python removes assertions under
`python -O`. Use `if` and an exception for a guard that must run in optimized
Python. An Action requiring every Post can call
`Contract.Postconditions(agent)` and raise the failing promise.

`KeyboardInterrupt`, `SystemExit` and other Python interruptions stop later
training immediately. TOP still attempts admission and checks current Posts,
then re-raises the original interruption. A Post failure or warning hook must
not hide it.

## Contract truth and Agency membership are separate questions

With TOP contract truthiness, `if agent:` asks whether its current Posts
hold. It does not prove membership in any Agency. A Rogue can be truthy because
it has no current broken promise; Posts from its admitted Tags and surviving
Constant Posts still apply. A host with an explicit `__bool__` is
refused before becoming an Agent; a host's `__len__` remains available but
does not determine Agent truth. A named condition states exactly which safety
question you need answered.

Membership is a separate question: `agent in Electric` asks whether the
Agent is a sound member of Electric. `agent in Electric[:]` asks whether
it remains in Electric's Field even when deficient. Check the specific Agency
when an operation requires a valid member of it:

```python
if electric in Electric:
    assert electric.Insulated           # sound membership in this Agency

electric.insulated = False
assert electric not in Electric         # deficient: not in the sound population
assert electric in Electric[:]          # whole Field includes deficient members
assert electric in ~Electric
assert not electric

electric.insulated = True
assert electric in Electric

del Electric[electric]
assert electric not in Electric[:]
electric.insulated = False
assert electric.Insulated is False       # admitted Constant Post survives Rip
assert not electric
```

Constant fixes the admitted Post's definition, not its answer: changing the
Agent can change whether the promise holds. An ordinary Post ends when its
Agent leaves that Tag's Field. A Constant Post is the deliberate exception,
like an NDA that remains binding after someone leaves an Agency.

`Electric[:]` is useful for diagnostics and cleanup that must include deficient
members. `isinstance(agent, Electric)` records having belonged; it remains true
after Rip and cannot serve as a current admission or safety check. Membership
and truthiness checks do not replace the named safety guard inside a hazardous
Action.

## Posts define what a finished Agent must have

Presence asks whether a Contribution exists, independently of its value.
Use it to make a Gain a requirement:

```python
class Account(Tag):
    @Record
    def balance(agent):
        return None

    @Post
    def Has_Balance(agent):
        return "balance" @ agent


account = Host()
Account(account)
assert bool(account)                      # None is a present value

del account.balance
assert account in Account[:]              # deficient, still a member
assert account in ~Account
assert not bool(account)

account.balance = False
assert bool(account)                      # False is also present
```

An assert-style Post can instead say `assert "balance" @ agent`. Python
removes assertions under `python -O`; return the Boolean when the check must
remain active in optimized Python. Presence does not certify a useful value:
use short-circuit logic for additional requirements, such as
`("balance" @ agent) and agent.balance is not None and agent.balance >= 0`.

## A Post failure preserves admission

```python
class Vehicle(Tag):
    @Record
    def running(agent):
        return False

    @Post
    def Runs(agent):
        return agent.running


car = Host()
try:
    Vehicle(car)
except TagPostconditionError.Runs:
    pass

assert car not in Vehicle
assert car in Vehicle[:]
assert car in ~Vehicle

car.running = True
assert car in Vehicle                    # repair changes soundness, not membership
assert car not in ~Vehicle
```

Gate refusal leaves that Tag unstarted. Training failure leaves its actual
Gains outside the Agency. Post failure leaves an admitted, deficient Agent.
Earlier completed Tags remain in every case; their current Posts still judge
the Agent's current state.

## Training through a temporary Base

Tagging a Shape applies its missing Bases first. Afterwards, each Tag has its
own Field membership. It is legal to apply a Shape and then Rip its Base:

```python
class Trainee(Tag):
    @Record
    def qualification(agent):
        return "pending"

    @Imprint
    def Practice(agent):
        agent.qualification = "trained"

    @Rip
    def Leave_Training(agent):
        agent.attempts.append("training ended")


class Certified(Trainee):
    @Post
    def Qualified(agent):
        return agent.qualification == "trained"


trainee = Host()
Certified(trainee)                 # Trainee enters first, then Certified
del Trainee[trainee]              # runs only Trainee's Rip protocol

assert trainee in Certified[:]
assert trainee not in Trainee[:]
assert trainee.qualification == "trained"
assert trainee.attempts == ["training ended"]
assert isinstance(trainee, Trainee)  # Tagging history is not membership
Certified(trainee)                 # active Shape: no new Tagging
assert trainee not in Trainee[:]
```

This is useful when being a Trainee is a real temporary Agency status. It is
usually a poor way to run training *solely* for the final Tag: Trainee's
Gate, Gainings, Imprints, Field admission and Rip all really happen. Rip
leaves acquired Actions and Records in place by default; a `@Rip` teardown
can explicitly change them. Ordinary Posts from the removed Tag end with its
Field membership, while Constant Posts survive. A later Shape can reapply a
missing Base; explicitly calling `Trainee(trainee)` starts fresh Base Tagging.
Base Rip does not automatically repair or Rip its Shape.

When preparation belongs to the final Tag, put it in that Tag's Imprint.
Its Record gives an initial value; the Imprint trains with that Gain before
the Agent enters the Field; a Post states the finished requirement:

```python
class Prepared(Tag):
    @Record
    def qualification(agent):
        return "pending"

    @Imprint
    def Practice(agent):
        agent.qualification = "trained"

    @Post
    def Qualified(agent):
        return agent.qualification == "trained"


prepared = Host()
Prepared(prepared)
assert prepared in Prepared[:]
assert prepared.qualification == "trained"
assert prepared
```

An Imprint runs **after** its Tag's Gate and earlier Gains. If preparation
must happen before that Gate or before a Record builder calculates its
initial value, perform it explicitly first, for example through an Action
of an already held Tag. Keep a separate training Tag when its membership
itself matters, rather than using a disposable Base as a subroutine.

## Cleanup after training failures

An ordinary Record initializer or Imprint failure does not prevent Field
entry. If training warns but Posts hold, Tagging returns normally. If Posts
fail, membership remains even though Tagging raises. Use `agent in MyTag[:]`
when deciding explicit cleanup after that failure. A structural refusal that
never admits the Target has no membership to Rip. TOP does not undo training's
world effects.

Preconditions, Posts and Record calculations read and query. TOP refuses
explicit acts such as Tagging, Rip, contract deletion and new Tag creation
while they run, including through an Action called for a value. Direct Python
writes, mutable values and external effects remain the author's responsibility.

## Cleanup after admission: the Safehouse

Once an Agent has entered a Field, explicit Rip removes its membership and
ordinary Post layers before cleanup. The Rip protocols then run sequentially.
A failure stops that attempt; completed protocols stay completed, while the
failed protocol and its remaining suffix are saved. The Agent is arrested
until all its saved work succeeds:

```python
from TopKit import TagCompositionError

release_available = {"now": False}
release_events = []


class Registered(Tag):
    @Rip
    def Release(agent):
        release_events.append("release")
        if not release_available["now"]:
            raise RuntimeError("registration service is unavailable")

    @Rip
    def Finish(agent):
        release_events.append("finish")


registered = Host()
Registered(registered)
try:
    del Registered[registered]
except TagCompositionError:
    pass

assert registered not in Registered[:]
assert registered in Registered[...]
assert not registered
assert release_events == ["release"]

release_available["now"] = True
del Registered[registered]             # resume the original saved Rip
assert release_events == ["release", "release", "finish"]
assert registered not in Registered[...]
```

Arrest is separate from broken Posts. An arrested Agent appears in neither
the sound nor broken population of any Tag, even if it still belongs to that
Tag's raw `[:]` Field. `MyTag[...]` answers a different question: does MyTag
still owe this Agent cleanup? Ordinary reads, writes and TOP calls retry saved
Rip first, refusing with `TagArrestedAccessError` if cleanup still fails. A
Rip protocol may perform the acts needed for its own Agent's cleanup.

`del MyTag[:]` removes every starting member before the first cleanup
callback. It stops at the first failure or interruption, keeping unfinished
work even for members whose callbacks have not run. Cleanup has no priority
between Field members: explicitly retrying another member is allowed.

The saved cursor is per declared protocol, including its composed Underlay.
Partial effects inside a failed protocol may therefore repeat; write cleanup
so it can retry. Python interruptions preserve their original exception and
pending work. Root dynamic membership queries, orphan Tag deletion and Fix
protocols are separate work; this page does not describe them as implemented.
