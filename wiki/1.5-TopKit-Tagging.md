# Tagging: training before Agency membership

**Gate → Gainings → Imprints → FieldAdding → Posts**

Each missing Tag takes its own turn, Bases first. Its Gate judges the Agent
as it is now. Preconditions are temporary Gate services: they answer that
Tagging attempt and never become Agent state or Contract status. Actions,
Records and deletions then take effect top to bottom in declaration order,
each visible to later declarations. Imprints train with acquired Gains.
FieldAdding admits the Agent only after that training finishes; only then do
that Tag's Posts become the Agent's Contract and judge the finished Agent.

A failed Post leaves a deficient member: a broken assembled car is still a
car. Failed training before FieldAdding leaves acquired Action and Record
Gains without membership, but none of that unfinished Tag's Posts: a Rogue
with respect to that Tag has no contract with an Agency it never joined.

The Python blocks below run in order as one program.

## A Rogue can retry through normal Tagging

```python
from TopKit import (Action, Constant, Contract, Imprint, Post, Pre, Public, Record,
                    Report, Rip, Tag, TagImprintError, TagPostconditionError)


class Host:
    def __init__(agent):
        agent.allowed = True
        agent.training_ready = False
        agent.attempts = []


class Driver(Tag):
    @Pre
    def May_Train(agent):
        return agent.allowed

    @Action
    def Start(agent):
        return agent.engine

    @Record
    def engine(agent):
        return "assembled"

    @Record
    def initial_check(agent):
        return agent.Start()             # earlier Action and Record are visible

    @Public
    @Report
    def badge(tag):
        return "Driver Agency"

    @Imprint
    def Train(agent):
        assert agent not in Driver       # acquired Gains, no membership yet
        agent.attempts.append("training")
        if not agent.training_ready:
            raise RuntimeError("training interrupted")


driver = Host()
try:
    Driver(driver)
except TagImprintError.Train:
    pass

assert driver not in Driver
assert not isinstance(driver, Driver)    # this attempt never entered the Agency
assert "Start" @ driver
assert "engine" @ driver
assert driver.initial_check == "assembled"
assert driver.Start() == "assembled"     # the Rogue keeps actual Gains
assert driver not in Driver[:]           # Field cleanup cannot find this Rogue
assert Contract.Status(driver) == {}      # Driver's Contract never started
assert not hasattr(driver, "May_Train")  # Preconditions never become Agent state
```

Calling the Tag again passes a fresh Gate, overlays ordinary Gains and
restarts Imprints. It does not resume at the failed instruction. Successfully
established Constants remain protected; a Constant Record whose builder
failed has no initialized binding to preserve.

In TopKit, a Gain needing runtime protection sticks only when its guard can
be installed. If that fails, the previous binding and earlier Gains remain.
If preparation of admission-time shared services fails, existing Agency
services remain; acquired Gains and completed Imprint effects are kept.

```python
driver.training_ready = True
Driver(driver)

assert driver in Driver
assert isinstance(driver, Driver)
assert driver.attempts == ["training", "training"]
assert driver.badge == "Driver Agency"   # published access after FieldAdding
```

During training, the Tag's published Reports and Operations and its bound
view are unavailable through the Agent. Previously admitted Tags keep their
ordinary access rules. Applying the same Tag to the same Agent while its
training is underway is a no-op.

Post declarations may occur before Imprints in the class body, but they remain
provisional during training. An unfinished attempt contributes no ordinary or
Constant Post. `@Constant` changes how long an admitted promise lasts; it does
not make the promise begin before admission.

## Guard an Action that can outlive unfinished training

An unfinished Electric Agent can retain an Action, but not Electric's
Contract. Therefore an Action that can outlive failed training must guard the
underlying safety fact directly instead of relying on a Post that never began:

```python
class Electric(Tag):
    @Constant
    @Post
    def Insulated(agent):
        return agent.insulated

    @Action
    def Energize(agent):
        if not agent.insulated:
            raise PermissionError("insulation is required")
        agent.high_voltage = True       # effect only after the explicit guard
        return "energized"

    @Imprint
    def Assemble(agent):
        if not agent.training_ready:
            raise RuntimeError("assembly interrupted")


electric = Host()
electric.insulated = False
electric.high_voltage = False
try:
    Electric(electric)
except TagImprintError.Assemble:
    pass

assert electric not in Electric
assert not hasattr(electric, "Insulated")
assert Contract.Status(electric) == {}
assert bool(electric)                   # no current promise is broken
try:
    electric.Energize()
except PermissionError:
    pass
else:
    raise AssertionError("an unsafe Agent was energized")
assert not electric.high_voltage

electric.insulated = True
assert electric.Energize() == "energized"
assert electric.high_voltage
assert electric not in Electric        # safe Gains do not establish membership
```

The explicit guard matters: declaring a Post does not automatically wrap
ordinary Action calls, and a provisional Post cannot guard a Rogue. Presence
such as `"insulated" @ agent` can be part of the direct guard when the value
itself may be absent.

After successful Field admission, `agent.Insulated` becomes an available
named guard. `assert agent.Insulated` is compact, but Python removes assertions
under `python -O`. Use `if` and an exception for a guard that must also run in
optimized Python. An Action needing every current Post can use the existing
`Contract.Postconditions(agent)` API to check them and raise a named failure.

## Contract truth and Agency membership are separate questions

With TOP contract truthiness, `if agent:` asks whether its current Posts
hold. It does not prove membership in any Agency. A Rogue can be truthy because
the failed Tagging added no promise; Posts from its other admitted Tags and
surviving Constant Posts still apply. A host with an explicit `__bool__` is
refused before becoming an Agent; a host's `__len__` remains available but
does not determine Agent truth. A named condition states exactly which safety
question you need answered.

Membership is a separate question: `agent in Electric` asks whether the
Agent is a sound member of Electric. `agent in Electric[:]` asks whether
it remains in Electric's Field even when deficient. Check the specific Agency
when an operation requires a valid member of it:

```python
electric.training_ready = True
Electric(electric)

if electric in Electric:
    assert electric.Insulated           # sound membership in this Agency

electric.insulated = False
assert electric not in Electric         # deficient: not in the sound population
assert electric in Electric[:]          # whole Field includes deficient members
assert electric in ~Electric
assert not electric

electric.insulated = True
assert electric in Electric

del Electric[electric]
assert electric not in Electric[:]
electric.insulated = False
assert electric.Insulated is False       # admitted Constant Post survives Rip
assert not electric
```

Constant fixes the admitted Post's definition, not its answer: changing the
Agent can change whether the promise holds. An ordinary Post ends when its
Agent leaves that Tag's Field. A Constant Post is the deliberate exception,
like an NDA that remains binding after someone leaves an Agency.

`Electric[:]` is useful for diagnostics and cleanup that must include deficient
members. `isinstance(agent, Electric)` records having belonged; it remains true
after Rip and cannot serve as a current admission or safety check. Membership
and truthiness checks do not replace the named safety guard inside a hazardous
Action.

## Posts define what a finished Agent must have

Presence asks whether a Contribution exists, independently of its value.
Use it to make a Gain a requirement:

```python
class Account(Tag):
    @Record
    def balance(agent):
        return None

    @Post
    def Has_Balance(agent):
        return "balance" @ agent


account = Host()
Account(account)
assert bool(account)                      # None is a present value

del account.balance
assert account in Account[:]              # deficient, still a member
assert account in ~Account
assert not bool(account)

account.balance = False
assert bool(account)                      # False is also present
```

An assert-style Post can instead say `assert "balance" @ agent`. Python
removes assertions under `python -O`; return the Boolean when the check must
remain active in optimized Python. Presence does not certify a useful value:
use short-circuit logic for additional requirements, such as
`("balance" @ agent) and agent.balance is not None and agent.balance >= 0`.

## A Post failure preserves admission

```python
class Vehicle(Tag):
    @Record
    def running(agent):
        return False

    @Post
    def Runs(agent):
        return agent.running


car = Host()
try:
    Vehicle(car)
except TagPostconditionError.Runs:
    pass

assert car not in Vehicle
assert car in Vehicle[:]
assert car in ~Vehicle

car.running = True
assert car in Vehicle                    # repair changes soundness, not membership
assert car not in ~Vehicle
```

Gate refusal leaves that Tag unstarted. Training failure leaves its actual
Gains outside the Agency. Post failure leaves an admitted, deficient Agent.
Earlier completed Tags remain in every case; their current Posts still judge
the Agent's current state.

## Training through a temporary Base

Tagging a Shape applies its missing Bases first. Afterwards, each Tag has its
own Field membership. It is legal to apply a Shape and then Rip its Base:

```python
class Trainee(Tag):
    @Record
    def qualification(agent):
        return "pending"

    @Imprint
    def Practice(agent):
        agent.qualification = "trained"

    @Rip
    def Leave_Training(agent):
        agent.attempts.append("training ended")


class Certified(Trainee):
    @Post
    def Qualified(agent):
        return agent.qualification == "trained"


trainee = Host()
Certified(trainee)                 # Trainee enters first, then Certified
del Trainee[trainee]              # runs only Trainee's Rip protocol

assert trainee in Certified[:]
assert trainee not in Trainee[:]
assert trainee.qualification == "trained"
assert trainee.attempts == ["training ended"]
assert isinstance(trainee, Trainee)  # Tagging history is not membership
Certified(trainee)                 # active Shape: no new Tagging
assert trainee not in Trainee[:]
```

This is useful when being a Trainee is a real temporary Agency status. It is
usually a poor way to run training *solely* for the final Tag: Trainee's
Gate, Gainings, Imprints, Field admission and Rip all really happen. Rip
leaves acquired Actions and Records in place by default; a `@Rip` teardown
can explicitly change them. Ordinary Posts from the removed Tag end with its
Field membership, while Constant Posts survive. A later Shape can reapply a
missing Base; explicitly calling `Trainee(trainee)` starts fresh Base Tagging.
Base Rip does not automatically repair or Rip its Shape.

When preparation belongs to the final Tag, put it in that Tag's Imprint.
Its Record gives an initial value; the Imprint trains with that Gain before
the Agent enters the Field; a Post states the finished requirement:

```python
class Prepared(Tag):
    @Record
    def qualification(agent):
        return "pending"

    @Imprint
    def Practice(agent):
        agent.qualification = "trained"

    @Post
    def Qualified(agent):
        return agent.qualification == "trained"


prepared = Host()
Prepared(prepared)
assert prepared in Prepared[:]
assert prepared.qualification == "trained"
assert prepared
```

An Imprint runs **after** its Tag's Gate and earlier Gains. If preparation
must happen before that Gate or before a Record builder calculates its
initial value, perform it explicitly first, for example through an Action
of an already held Tag. Keep a separate training Tag when its membership
itself matters, rather than using a disposable Base as a subroutine.

## Cleanup of unfinished training

Never entering the Field means there is nothing to Rip. Failed training
triggers no automatic `@Rip` and is outside `Tag[:]`. Imprints that acquire
resources should arrange ordinary Python exception handling for an unfinished
attempt. TOP does not undo world effects. Preconditions judge by reading and
querying; Record builders read and query to calculate initial returned values.
Applying or Ripping Tags and performing world effects belong to Imprints.
These are authoring rules, not an automatic Python sandbox.

## Cleanup after admission: the Safehouse

Once an Agent has entered a Field, explicit Rip removes its membership and
ordinary Post layers before cleanup. The Rip protocols then run sequentially.
A failure stops that attempt; completed protocols stay completed, while the
failed protocol and its remaining suffix are saved. The Agent is arrested
until all its saved work succeeds:

```python
from TopKit import TagCompositionError

release_available = {"now": False}
release_events = []


class Registered(Tag):
    @Rip
    def Release(agent):
        release_events.append("release")
        if not release_available["now"]:
            raise RuntimeError("registration service is unavailable")

    @Rip
    def Finish(agent):
        release_events.append("finish")


registered = Host()
Registered(registered)
try:
    del Registered[registered]
except TagCompositionError:
    pass

assert registered not in Registered[:]
assert registered in Registered[...]
assert not registered
assert release_events == ["release"]

release_available["now"] = True
del Registered[registered]             # resume the original saved Rip
assert release_events == ["release", "release", "finish"]
assert registered not in Registered[...]
```

Arrest is separate from broken Posts. An arrested Agent appears in neither
the sound nor broken population of any Tag, even if it still belongs to that
Tag's raw `[:]` Field. `MyTag[...]` answers a different question: does MyTag
still owe this Agent cleanup? Ordinary reads, writes and TOP calls retry saved
Rip first, refusing with `TagArrestedAccessError` if cleanup still fails. A
Rip protocol may perform the acts needed for its own Agent's cleanup.

`del MyTag[:]` removes every starting member before the first cleanup
callback. It stops at the first failure or interruption, keeping unfinished
work even for members whose callbacks have not run. Cleanup has no priority
between Field members: explicitly retrying another member is allowed.

The saved cursor is per declared protocol, including its composed Underlay.
Partial effects inside a failed protocol may therefore repeat; write cleanup
so it can retry. Python interruptions preserve their original exception and
pending work. Root dynamic membership queries, orphan Tag deletion and Fix
protocols are separate work; this page does not describe them as implemented.
